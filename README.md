## 📖 О проекте

**Project Galaxority** — это 3D-игра в жанре космического приключения, где игрок исследует
процедурно сгенерированные звёздные системы, пилотирует корабль и взаимодействует
с инопланетными цивилизациями.

> 🚀 *Отправляйтесь в путешествие сквозь бесконечные галактики — торговля, сражения, исследования.*

## ✨ Особенности

- 🌠 **Процедурная генерация** галактик и планет
- 🚀 **Свободное пилотирование** космического корабля
- 🪐 **Реалистичное управление**
- 👽 **Встречи с инопланетными расами**
- 🛸 **Система апгрейдов** и модификации корабля
- 🎮 **Поддержка геймпада** и клавиатуры

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/username/galaxority.git

# Перейти в директорию
cd galaxority

# Установить зависимости
uv sync

# Запустить игру
uv run game.py
```

## 🎮 Управление

| Действие             | Клавиша    |
|:---------------------|:-----------|
| Ускорение/замедление | `W/S`      |
| Поворот              | `A/D/Мышь` |
| Турбо скорость       | `Shift`    |
| Тормоз               | `Space`    |
| Огонь                | `ЛКМ`      |
| Карта                | `M`        |
