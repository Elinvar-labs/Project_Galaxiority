## 📖 О проекте

**Project Galaxority** — это 3D-игра в жанре космического приключения, где игрок исследует
процедурно сгенерированные звёздные системы, пилотирует корабль и взаимодействует
с инопланетными цивилизациями.

> 🚀 *Отправляйтесь в путешествие сквозь бесконечные галактики — торговля, сражения, исследования.*

## ✨ Особенности

- 🌠 **Процедурная генерация** галактик и планет
- 🚀 **Свободное пилотирование** космического корабля
- 🪐 **Реалистичное управление**
- 👽 **Встречи с инопланетными расами**
- 🛸 **Система апгрейдов** и модификации корабля
- 🎮 **Поддержка геймпада** и клавиатуры

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Elinvar-labs/Project_Galaxiority

# Перейти в директорию
cd galaxiority

# Установить зависимости
uv sync

# Запустить игру
uv run project-galaxiority
```

## 🎮 Управление

| Действие           | Клавиатура/мышь | Геймпад                    |
|:-------------------|:----------------|:---------------------------|
| Прицел (yaw/pitch) | Мышь / стрелки  | Левый стик                 |
| Roll               | A / D           | Правый стик X              |
| Тяга               | W / S + колесо  | RT / LT                    |
| Brake              | Space           | B (Right Face Right)       |
| Boost              | Shift           | A (Right Face Down)        |
| **Primary fire**   | **ЛКМ / Ctrl**  | **RB** (`RIGHT_TRIGGER_1`) |
| **Secondary fire** | **ПКМ / Alt**   | **LB** (`LEFT_TRIGGER_1`)  |
| Quit               | Esc             | Start                      |
| Quit               | Esc             | Start                      |

#### Также поддерживаются игровые геймпады!
